Uninty Team Project
=======================
This game is 2D-Top View Rpg

1.Basic Game structure\n
  Player start at village with something story.
  Player have to find trigger object that can enter monster zone.
  When Player enter the monster zone, Player have to fight with mini monster given exp.
  Player can inhance their abillity by getting exp from the mini monster.
  After few times, Boss come out around Player.  
  If Player kill Boss, Player get some items and can go out monster zone.
